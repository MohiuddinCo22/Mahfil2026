# মিলাদুন্নবী মাহফিল হিসাব — Web App

কাগজ-কলমের বদলে চাঁদা ও খরচের হিসাব ডিজিটালি রাখার জন্য একটি ফ্রি ওয়েব অ্যাপ।
**GitHub Pages** (ফ্রি হোস্টিং) + **Firebase** (ফ্রি ডাটাবেজ ও লগইন) দিয়ে বানানো — কোনো টাকা খরচ ছাড়াই ব্যবহার করা যাবে।

---

## যা যা পাবেন

- **চাঁদা এন্ট্রি**: নাম, ঠিকানা, রেফারেন্স, এমাউন্ট, তারিখ
- **ড্যাশবোর্ড**: ৫০০ / ১০০০ / ২০০০ / ৩০০০ / ৪০০০ / ৫০০০ টাকার বক্স — কতজন কত টাকা করে দিয়েছে তার কাউন্ট ও টোটাল, ক্লিক করলে ফিল্টার হয়ে তালিকা দেখাবে
- **খরচের হিসাব**: আলাদা সেকশনে খরচ যোগ ও তালিকা
- **মোট সংগ্রহ, মোট খরচ, ব্যালেন্স** — অটো হিসাব
- **২-৩ জন কমিটি মেম্বার লগইন** — পাবলিক সাইনআপ নেই, শুধু আপনি যাদের অ্যাকাউন্ট বানাবেন তারাই ঢুকতে পারবে
- সব ডাটা রিয়েল-টাইমে সব মেম্বারের স্ক্রিনে সিঙ্ক হবে

---

## ধাপ ১: Firebase প্রজেক্ট তৈরি করুন (ফ্রি)

1. https://console.firebase.google.com এ যান, Google অ্যাকাউন্ট দিয়ে লগইন করুন
2. **Add project** এ ক্লিক করুন, একটা নাম দিন (যেমন: `milad-mahfil-hishab`)
3. Google Analytics এর অপশন আসলে বন্ধ (off) করে দিতে পারেন, দরকার নেই
4. প্রজেক্ট তৈরি হয়ে গেলে ড্যাশবোর্ডে চলে যান

## ধাপ ২: Authentication (লগইন সিস্টেম) চালু করুন

1. বাম মেনু থেকে **Build > Authentication** এ যান
2. **Get started** ক্লিক করুন
3. **Sign-in method** ট্যাবে গিয়ে **Email/Password** সিলেক্ট করে **Enable** করুন, Save করুন
4. **Users** ট্যাবে গিয়ে **Add user** দিয়ে আপনার ২-৩ জন কমিটি মেম্বারের জন্য ইমেইল + পাসওয়ার্ড দিয়ে অ্যাকাউন্ট বানিয়ে দিন
   (এই ইমেইল-পাসওয়ার্ড দিয়েই তারা অ্যাপে লগইন করবে)

## ধাপ ৩: Firestore ডাটাবেজ চালু করুন

1. বাম মেনু থেকে **Build > Firestore Database** এ যান
2. **Create database** ক্লিক করুন
3. Location হিসেবে কাছের কোনো একটা রিজিওন সিলেক্ট করুন (যেমন `asia-south1`), Next চাপুন
4. **Start in production mode** সিলেক্ট করে Enable করুন
5. ডাটাবেজ তৈরি হয়ে গেলে উপরে **Rules** ট্যাবে যান, এই প্রজেক্টের `firestore.rules` ফাইলের কন্টেন্ট কপি করে পেস্ট করুন, **Publish** চাপুন
   (এই rules নিশ্চিত করে যে শুধু লগইন করা কমিটি মেম্বাররাই ডাটা দেখতে/যোগ করতে পারবে)

## ধাপ ৪: Web App যোগ করে Config নিন

1. Firebase Console এ প্রজেক্টের **Settings (⚙️) > Project settings** এ যান
2. নিচে **Your apps** সেকশনে **</>** (Web) আইকনে ক্লিক করুন
3. একটা নিকনেম দিন (যেমন `mahfil-web`), **Register app** করুন
4. যে `firebaseConfig = {...}` কোডটা দেখাবে, সেটা পুরোপুরি কপি করুন
5. এই প্রজেক্টের `firebase-config.js` ফাইল খুলে, ওখানে যে placeholder মান আছে (`PASTE_YOUR_API_KEY_HERE` ইত্যাদি) — সেগুলোর জায়গায় আপনার আসল কনফিগ বসিয়ে সেভ করুন

## ধাপ ৫: GitHub Pages এ ফ্রি হোস্ট করুন

1. https://github.com এ একটা নতুন **repository** বানান (যেমন `milad-mahfil-hishab`), Public রাখুন
2. এই ফোল্ডারের সব ফাইল (`index.html`, `app.html`, `app.js`, `style.css`, `firebase-config.js`, `firestore.rules`, `README.md`) সেই repository তে আপলোড করুন
   - সহজ উপায়: GitHub repo পেজে **Add file > Upload files** দিয়ে সব ফাইল ড্র্যাগ করে দিন, তারপর **Commit changes**
3. Repo এর **Settings > Pages** এ যান
4. **Branch** এ `main` সিলেক্ট করে **Save** করুন
5. কিছুক্ষণ পর একটা লিংক পাবেন (যেমন `https://your-username.github.io/milad-mahfil-hishab/`) — এটাই আপনার অ্যাপের ঠিকানা, এটা কমিটি মেম্বারদের সাথে শেয়ার করুন

## ধাপ ৬: Firebase-কে বলুন এই ডোমেইন থেকে লগইন allow করতে

1. Firebase Console > Authentication > **Settings** ট্যাব > **Authorized domains**
2. **Add domain** দিয়ে আপনার GitHub Pages এর ডোমেইন যোগ করুন (যেমন `your-username.github.io`)

---

## ব্যবহার

- `https://your-username.github.io/milad-mahfil-hishab/` এ গেলে লগইন পেজ আসবে
- কমিটি মেম্বার তাদের ইমেইল-পাসওয়ার্ড দিয়ে লগইন করবে
- **চাঁদা** ট্যাব থেকে নতুন চাঁদা যোগ করা যাবে, তালিকা ও এমাউন্ট অনুযায়ী ফিল্টার দেখা যাবে
- **খরচ** ট্যাব থেকে খরচ যোগ করা যাবে
- **ড্যাশবোর্ড** এ সব হিসাবের সামারি ও এমাউন্ট-ভিত্তিক ব্রেকডাউন দেখা যাবে

## নাত প্লেয়ার যোগ করা

অ্যাপে ঢোকার পর নাত বাজানোর জন্য:

1. আপনার পছন্দের নাতের mp3 ফাইলটা (যেটা ব্যবহারের অনুমতি/লাইসেন্স আপনার আছে) নিন
2. ফাইলের নাম পরিবর্তন করে ঠিক **`naat.mp3`** রাখুন
3. এই প্রজেক্টের অন্য ফাইলগুলোর (index.html, app.js ইত্যাদি) পাশেই `naat.mp3` ফাইলটা রাখুন এবং GitHub এ আপলোড করুন

অ্যাপ খোলার সাথে সাথে এটা বাজার চেষ্টা করবে। কোনো কোনো ব্রাউজার (বিশেষ করে মোবাইল সাফারি/ক্রোম) সাউন্ডসহ auto-play আটকে দেয় — তখন ডান-নিচে **"▶️ নাত শুনুন"** বাটন দেখাবে, একবার ট্যাপ করলেই বাজা শুরু হবে।

> কপিরাইটের কারণে নাতের অডিও ফাইল আমি সরাসরি সরবরাহ করিনি — নিজের রেকর্ড করা বা অনুমতিপ্রাপ্ত নাত ব্যবহার করবেন।

## ব্যানার এডিট করা

ড্যাশবোর্ডের উপরের ব্যানারের লেখা (প্রতিষ্ঠানের নাম ও মাহফিলের টাইটেল) পরের বছর পরিবর্তন করতে হলে `app.html` ফাইলে `event-banner` অংশ খুঁজে টেক্সট বদলে দিলেই হবে।

## খরচ

Firebase এর ফ্রি (Spark) প্ল্যানেই এই সাইজের অ্যাপ চলে যাবে — একটা মাহফিলের জন্য কয়েকশ এন্ট্রি রাখতে কোনো টাকা লাগবে না। GitHub Pages হোস্টিং সম্পূর্ণ ফ্রি।
